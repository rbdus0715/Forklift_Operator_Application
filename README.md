## 개발 계기
> 2024년 제조업 사망 사고 원인 1위는 지게차 관련 사고<br>
> 지게차 사각지대로 인해 보행자를 위협하는 문제가 발생<br>
> 사각지대를 없애기 위한 솔루션 개발<br>


## 기능
<img width="837" height="335" alt="image" src="https://github.com/user-attachments/assets/879c9a84-4757-48b9-89d5-8e083c4c496e" />
<br>

| 기능 | 상세 내용 | 활용 기술 | 표출 매체 |
| :--- | :--- | :--- | :--- |
| **위치 파악 및 알람** | 보행자 및 지게차의 위치 파악 및 실시간 위험 알림 | UWB 기반 센서 | 웨어러블, 앱 |
| **사고 시나리오 알람** | 과속, 지게차 회전, 근접 거리 등 시나리오별 알람 발생 | 알람 시스템 | 웨어러블, 앱 |
| **동선 및 히트맵 시각화** | 작업자/장비의 이동 동선 및 밀집 구역 시각화 모니터링 | 유니티, Advantech Wise-PaaS | 관제 모니터 |
| **통계 및 조회** | 구역별 위험 점수 집계 및 지게차 운행 데이터 조회 | 통계 분석 시스템 | 관리자 대시보드 |


주요 언어
- C++, Python, React Native(typescript), NodeJS


주요 업무
- 앱 개발
- 하드웨어의 데이터를 클라우드 플랫폼으로 전송하기 위한 MQTT 프로토콜 기반 API 개발
- 웨어러블과의 소켓통신
- 칼만 필터를 통한 센서-하드웨어에서 발생하는 노이즈 스무딩
